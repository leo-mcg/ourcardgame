# Our Card Game: landing page

A one-page splash site for [Our Card Game](https://ourcardgame.ca), a free virtual deck of cards and card table for you and your friends, created by Glen Little.

**Live:** https://leo-mcg.github.io/ourcardgame/

- Plain static HTML and CSS (`index.html`, `styles.css`), with no build step and no JavaScript.
- The card art is illustrated in CSS. The "See it in action" section uses a real app screenshot from the client (`img/screenshot-estimation.webp`, with a PNG fallback). The app icon and favicon (`img/`) come from ourcardgame.ca.
- `og-image.png` is the 1200×630 social preview image.
- Published with GitHub Pages from `main` at `/`, and `.nojekyll` is included.
- Content comes from ourcardgame.ca and its [FAQ](https://ourcardgame.ca/faq).

Site by [Leo-McG](https://leo-mcg.github.io).
